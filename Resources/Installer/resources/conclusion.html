Two more steps

  1. Allow Espalier to control windows. System Settings → Privacy & Security → Accessibility: switch on Espalier. If Grid is new on this Mac, switch on Grid too. Espalier starts working as soon as it's allowed.
  2. F5 and F6. On a Mac keyboard they're media keys, so press them with fn, or turn on “Use F1, F2, etc. keys as standard function keys” in System Settings → Keyboard → Keyboard Shortcuts → Function Keys.

Espalier opens at login. If macOS asks, approve it in System Settings → General → Login Items. Its menu bar icon has Open at Login, settings and Quit.

Making tabs: drag a window by its title bar onto the top of another window, hold until the outline appears, and let go. Click a tab's × to close that window (⌥-click to quit its app).
